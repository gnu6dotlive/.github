# gnu6dotlive

**Local-first Linux computing, built in the open — with its evidence.**
*L'informatique locale sous Linux, construite à découvert — preuves comprises.*

### Start here → [**gnu6dotlive.github.io**](https://gnu6dotlive.github.io/en/) · Commencer ici → [**en français**](https://gnu6dotlive.github.io/)

The projects below on one live scene, each link between them backed by the file that proves it,
and dossiers written without jargon, in English and French. The first four dossiers are also kept
as a dated snapshot: [**prologue**](https://gnu6dotlive.github.io/prologue/en/), October 29, 2026.
