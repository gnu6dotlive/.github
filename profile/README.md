# gnu6dotlive

**Local-first Linux computing, built in the open — with its evidence.**
*L'informatique locale sous Linux, construite à découvert — preuves comprises.*

### Start here · Commencer ici → [**prologue**](https://gnu6dotlive.github.io/prologue/)

The four projects below, explained without jargon (in French), with what is proven and
what is still open. A dated snapshot: October 29, 2026.

| Project | What it is | Published state |
| --- | --- | --- |
| [**gnosix**](https://github.com/gnu6dotlive/gnosix) | A desktop environment for Linux, written in Rust on Wayland and GPUI | `v26.11-rc1` « Ardoise » · experimental · MIT |
| [**gnostral.rs**](https://github.com/gnu6dotlive/gnostral.rs) | A research lab for local inference on constrained GPUs, with published receipts | `v0.8.0` · research · MIT |
| [**Calix**](https://github.com/gnu6dotlive/calix) | A native package manager interface for Arch Linux, Rust + GPUI with a Zig engine | `v0.3.1` · pre-1.0 · GPL-3.0 |
| [**in.gnu6**](https://github.com/gnu6dotlive/in.gnu6) | A scene and topology engine: the scene decides what exists, renderers only draw it | `2026.10.0-research` · no license yet |

Also public: [gnosix.ds](https://github.com/gnu6dotlive/gnosix.ds) (design system) and
[engineering-corpus](https://github.com/gnu6dotlive/engineering-corpus).

Every claim in these repositories carries its level of proof — *proven*, *qualified*,
*open* — and the failed attempts stay on the record.
